# FrameX | EN3160 | CAMEL

Student PyTorch reimplementation of CAMEL:
Confidence-Aware Multi-task Ensemble Learning with Spatial
Information for Retina OCT Image Classification and Segmentation.

## Team
FrameX

## Module
EN3160

## Project goal
Reimplement the CAMEL method, demonstrate the code running,
and reproduce a selected part of the paper's experiments.

## Planned stages
1. Prepare and inspect the OCT dataset.
2. Build the data-loading pipeline.
3. Implement a joint classification and segmentation model.
4. Train and evaluate individual models.
5. Implement confidence-aware ensemble predictions.
6. Document results and prepare the demonstration.

## References
- Paper: Jung et al., WACV 2025.
- Official implementation: https://github.com/DSAIL-SKKU/CAMEL
